# smart-home-os

A self-hosted smart home platform on a Raspberry Pi: Zigbee devices via Zigbee2MQTT, a React dashboard,
routines (schedules, sunrise/sunset, sensor and button triggers, light fades, Spotify), and an LLM agent
that can control the home and create routines by chat or voice.
